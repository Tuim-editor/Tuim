# Tuim v0.3.0

Tuim 0.3.0 brings a unified workspace, a redesigned Extensions panel, and a
more responsive editor to Normal, IDE, and Zen modes.

## Highlights

- **Extensions in the workspace.** Installed opens immediately, with Discover
  beside it. Search plugins, inspect details, edit configuration, enable or
  disable plugins, and uninstall with confirmation. Wide terminals show lists
  and details side by side; compact terminals use a focused details view.
- **A complete installed library.** Bundled plugins, dependencies, marketplace
  additions, and local plugin directories are visible offline. State changes
  apply after restarting; disabling keeps plugin files and uninstalling keeps
  configuration. Required dependencies and the plugin manager are protected.
- **VS Code Dark Modern by default.** Treesitter comes prepared with 19 default
  parsers. The System theme option follows the desktop palette.
- **A shared workspace.** Normal and IDE modes share the Explorer and project
  tools. Hover feedback, command and buffer pickers, keyboard Git navigation,
  safer new-file saving, and terminal resizing improve everyday editing.
- **A more responsive foundation.** Bounded asynchronous RPC, background Git
  refresh, explicit redraw invalidation, retained composition regions, and
  terminal row-run output reduce unnecessary work and blocking interactions.
- **Simpler setup.** The installer selects and verifies native release bundles,
  installs required system dependencies, and prepares private tools and parsers.
- **Updated website and documentation.** Current software screenshots explain
  the workspace, editing modes, Extensions, installation, and platform limits.
  Obsolete UI v2 roadmaps, study notes, and prototype dumps have been removed;
  one current architecture guide replaces the overlapping specifications.

## Install or upgrade

Run the installer again; it preserves Tuim's settings and plugin data:

```sh
curl -fsSL https://raw.githubusercontent.com/Rouboufy/tuim/main/setup.sh | bash
```

Native bundles include Tuim and a private Neovim runtime for Linux and macOS
on x86-64 and ARM64. A Linux x86-64 AppImage is also provided. Checksums are in
`SHA256SUMS`. Run `tuim --version` to verify the installed version.

## Configuration and compatibility

Plugin config files now return lazy.nvim spec overrides, including `opts` and
`config`. An explicit `config` replaces Tuim's setup for that plugin. Back up
custom configurations before changing them; see [Extensions usage](../usage.md#extensions).

If a plugin config prevents normal startup, use `TUIM_DISABLE_PLUGINS=1 tuim`
to repair it without executing user plugin configurations. Installation and
removal changes take effect on the next normal startup.

Linux is the primary tested platform. macOS builds and headless checks pass,
but the macOS CI terminal smoke test can time out during interactive startup;
treat the macOS bundles as experimental. WSL still needs broader terminal testing. Clipboard, mouse, and modified keys depend on the terminal;
plugins that take over the outer terminal may need adjustments.
